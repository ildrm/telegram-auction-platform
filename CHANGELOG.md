# Changelog

All notable platform changes are documented here.

## 1.0.0 - 2026-07-30

### Added

- Telegram-first onboarding, signed idempotent webhook ingestion, persistent
  conversations, localized keyboards, and retryable queued delivery.
- English, hybrid, buy-now, Dutch, reverse, and sealed-bid auctions with proxy
  bidding, anti-sniping, reserve enforcement, and concurrency-safe closing.
- Moderation, reports, roles and permissions, audited administration, database
  translations, system settings, and Filament dashboard resources.
- Watchlists, durable in-app and Telegram notifications, and participant
  reviews.
- Validated private image uploads, queued WebP derivatives, signed media URLs,
  encrypted backup/restore, operational health checks, and release packaging.
- English and Persian messages, REST adapters, operator documentation, and
  comprehensive automated acceptance coverage.
